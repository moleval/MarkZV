# MarkZV — сбор данных, 2D-модель витража и марки стоек/ригелей

**Файл модуля:** [`MarkZV.lsp`](MarkZV.lsp) → копировать как `D:\MarkZV.lsp`
**Редакция:** `1.2` (версия.билд: версия — крупные задачи, билд — итерация правок)
**Кодировка рабочего файла:** CP1251 + CRLF, как в поставке MARKZ.lsp (в Git хранится как UTF-8 через `.gitattributes` / `working-tree-encoding`, поэтому diff на GitHub читаемый, а выгруженный файл — CP1251)
**Смежный проект:** [moleval/MarkZ](https://github.com/moleval/MarkZ) — маркировка заполнений, рядовка, ведомость

## Установка

```lisp
(load "D:/MarkZV.lsp")
```

## Команды

| Команда | Что делает |
|---------|------------|
| `МАРКАВГЕОМЕТРИЯ` | Сбор данных по выборке (режим «Мультилинии» или «Блоки»), границы витража, проверки, топология и типы примыканий, 2D-модель на слое `MK_MODEL`, дамп в `D:/MARKZV_MODEL.txt` |
| `МАРКАВМОДЕЛЬ` | Тестовая отрисовка по кэшу на слое `MK_TEST_MODEL` |
| `МАРКАВСТ` | Марки стоек: `<Витраж> Ст<N>` (+ `зерк` для зеркальных) |
| `МАРКАВРГ` | Марки ригелей: `<Витраж> Рг<N><суффикс>` |
| `МАРКАВДИАГНОЗ` | Диагностика блока: все атрибуты, все динамические свойства, габарит; дозапись в `D:/MARKZV_DIAG.txt` |
| `МАРКАВСКОБКИ` | Проверка баланса скобок исходника |

## Суффиксы ригелей

| Условие (сверху / снизу) | Суффикс |
|---|---|
| окно с одной стороны | `ок` |
| окно с обеих сторон | `окх2` |
| дверь | `дв` |
| тёплое (42–60) снизу / холодное (4–32) сверху | `тх` |
| холодное снизу / тёплое сверху | `хт` |
| ригель на уровне порога двери (±50 мм) | `+н` |

## Проверка перед коммитом

```bash
python3 tools/check_parens.py MarkZV.lsp   # аналог TEST 00 / МАРКАВСКОБКИ без AutoCAD
```

## Логика маркировки

Подробно — в [COMMANDS.md](COMMANDS.md). Коротко:

- **Стойки:** `<Витраж> Ст<N>`; группа = длина (допуск 0.5 мм) + атрибут «Артикул» + тип примыкания слева + тип примыкания справа. Зеркальная ориентация той же группы получает суффикс `зерк`.
- **Ригели:** `<Витраж> Рг<N><суффикс>`; группа = длина + артикул + суффикс окружения (`ок`, `окх2`, `дв`, `тх`, `хт`, `н`).
- Нумерация групп — в порядке появления: слева направо, снизу вверх.
- Длина/ширина/высота читаются из динамического свойства по маске, при отсутствии — из габарита блока (`BBOX`); источник виден в дампе.

## Изменения по редакциям

### Ред. 1.3

- Отрисовка `МАРКАВГЕОМЕТРИЯ` собирается в группу AutoCAD `MK_MODEL`, `МАРКАВМОДЕЛЬ` — в `MK_TEST_MODEL`: построение удаляется одним выбором (донор `mark:ar-make-group` из MarkZ).
- Исправлен дефект B7: панель считается примыкающей к ригелю только при перекрытии диапазонов по X — ложные суффиксы `ок` у ригелей соседних пролётов (`Рг13ок`, `Рг16ок`) больше не появляются.
- Ригели нумеруются по вертикальным столбцам (пролётам между осями стоек): все ригели одного столбца получают одну цифру.
- Маркеры размера профиля `м` / `б` при двух и более артикулах ригелей (по габариту сечения; ручная таблица `*mk:article-size*` имеет приоритет).
- В дамп добавлены поля `СЕЧЕНИЕ`, `СТОЛБЕЦ`, `РАЗМЕР` (ригели) и `СЕЧЕНИЕ` (стойки).
- `tools/sial_parse.py` — разбор «База СИАЛ.xlsx» в таблицу «артикул → габарит → м/б».

### Ред. 1.2

- Команды переименованы: `МАРКАВГЕОМЕТРИЯ`, `МАРКАВМОДЕЛЬ`, `МАРКАВСТ`, `МАРКАВРГ`, `МАРКАВДИАГНОЗ`, `МАРКАВСКОБКИ`.
- Атрибут профиля заменён на **`Артикул`** (`*mk:attr-article*`), в дампе колонка `АРТИКУЛ`.
- Стойки группируются с учётом **типа примыкания слева и справа**; зеркальные стойки получают ту же цифру и суффикс `зерк`.
- Нумерация групп — по порядку обнаружения: слева направо, снизу вверх.
- В дамп добавлены строки `СЛЕВА:` / `СПРАВА:` для стоек и `СУФФИКС:` для ригелей.
- `МАРКАВСКОБКИ` сама ищет исходник (`D:\MarkZV.lsp`, `D:\MarkZV\MarkZV.lsp`, `C:\Work\MarkZV\MarkZV.lsp`, `findfile`).

### Ред. 1.1

- Новая схема версий: `версия.билд`.
- Команды `МАРКАЗАПОЛН-СТ` / `МАРКАЗАПОЛН-РГ` работают **по выборке** (Enter — выборка последнего МАРКАСБОР), раньше молча брали весь чертёж и маркировали блоки за пределами выделения.
- Размеры: фолбэк на габарит блока `GetBoundingBox`, когда динамическое свойство по маске не найдено; в дампе печатается источник `DYN` / `BBOX` / `НЕТ`.
- Чтение динамических свойств переписано: единый разбор с перехватом ошибок + кэш по ename (раньше `vlax-get` вызывался без защиты и по 3 полных обхода на блок).
- Новая команда `МАРКАДИАГ` — показывает реальные имена свойств и атрибутов блока.
- Валидация ригелей учитывает отступ вставки от оси стойки (`*mk:offset-fill*` = 25 мм): исчезли массовые ложные `[ERROR] Ригель без примыкания`.

### Ред. 1.0 (бывш. r2)

- Восстановлена пропущенная `)` в `mk:extract-posts-beams-from-mlines` (файл не загружался).
- **B2:** `mk:group-by-size-profile` / `mk:group-beams` — группы копились в переменной цикла, в группу попадал только первый элемент, остальные стойки/ригели оставались без «Марки». Переписано на `assoc` + `subst` (`mk:group-add`), ключ размера — с допуском `*mk:tol-size*` 0.5 мм.
- **B3:** обновление полей записей шло через `append`, а `assoc` возвращал старое значение — не работали `INS_PT` после нормализации, `PROTRUDING`, `LEFT_CONN`/`RIGHT_CONN`, `TOP_ELEM`/`BOT_ELEM`, `SUFFIX`. Введён `mk:rec-put` (замена через `subst`).
- **B4:** убраны `(exit)` — команды завершаются штатно, без «quit / exit abort».
- **B5:** одна выборка `ssget "_X"` на команду вместо пяти; запись марок — в одной транзакции `StartUndoMark`/`EndUndoMark` (откат одним `_U`).
- Добавлены `*mk:rev*` / `*mk:build*` и версия в баннере загрузки.
